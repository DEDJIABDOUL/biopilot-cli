# Code of Conduct

BioPilot CLI adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct. Everyone taking part in the project (issues, pull requests, discussions, and any event or channel where the project is represented) is expected to follow it.

## In short

- Be welcoming to people of every background, career stage and level of experience: students, lab technicians, research engineers and software developers alike.
- Discuss the work, not the person. Disagree with arguments and evidence.
- Do not harass, insult, demean or publish anyone's private information.
- Credit other people's work, including the authors of the tools BioPilot completes.

## Reporting

To report behaviour that breaks this code, contact the maintainer privately through the e-mail address on the [maintainer's GitHub profile](https://github.com/DEDJIABDOUL), or by a private GitHub message. Reports are handled confidentially. The maintainer will acknowledge a report within 7 days and act following the enforcement guidelines of the Contributor Covenant (correction, warning, temporary ban, permanent ban).
