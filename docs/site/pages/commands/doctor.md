# biopilot doctor

Check that the installation is complete.

```text
biopilot doctor
```

It checks:

- the shell start lines;
- the tool database (Catalog);
- the user data (User store);
- the `PATH`;
- the active environment.

It names each problem it finds and what to do about it.
