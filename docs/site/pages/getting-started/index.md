# Get started

BioPilot is a standalone program installed in your home folder. It needs no administrator rights, no Node.js and no compiler, and it works offline once installed.

1. Check the [requirements](requirements.md).
2. [Install](installation.md) BioPilot and add its start line to your shell.
3. Follow the [first steps](first-steps.md) to check that it runs and read your tools' real options.

!!! note "BioPilot does not install your tools"
    BioPilot helps with the bioinformatics tools you already have, in a conda environment or anywhere on your `PATH`. It does not install them.
