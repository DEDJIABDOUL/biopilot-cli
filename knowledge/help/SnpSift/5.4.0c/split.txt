Usage: java -jar SnpSift.jar splitChr [-j] [-l <num>] file.vcf [file_2.vcf ... file_N.vcf]
Options:
	-j         : Join all files in command line (output = STDOUT).
	-l <num>   : Split by 'num' lines.
	Default    : Split by chromosome (one file per chromosome).
